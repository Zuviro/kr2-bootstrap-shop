## Описание проекта

Проект представляет собой учебный интернет-магазин атмосферных осенних декораций «Pumpkin». 
Это полностью переработанная версия проекта КР №1, которая вместо чистого CSS теперь базируется на CSS-фреймворке Bootstrap 5. 
При этом сохранен оригинальный визуальный стиль, цветовая палитра и предметная область первой работы.

---

## Используемые технологии

- **HTML5** (семантическая разметка);
- **Bootstrap 5.3.3** (подключен **локально** без CDN);
- **CSS3** (кастомная стилизация через файл `css/custom.css`);
- **JavaScript** (ES6) для клиентской фильтрации и обработки форм;
- **Git, GitHub**.

---

## Способ подключения Bootstrap

Bootstrap подключён **локально** (без использования CDN). Файлы фреймворка размещены в каталоге `vendor/bootstrap/`:
- `vendor/bootstrap/css/bootstrap.min.css`
- `vendor/bootstrap/js/bootstrap.bundle.min.js`

Для быстрой загрузки файлов фреймворка в проект написан скрипт `scripts/download-bootstrap.ps1` (для Windows).
